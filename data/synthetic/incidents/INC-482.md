# Incident INC-482

Date: August 16, 2026

Severity: SEV-2

Service: Authentication

## Summary

Several customers reported increased authentication failures following the deployment of NimbusFlow v2.18.

## Symptoms

Customers experienced elevated `TOKEN_EXPIRED` errors when applications attempted to refresh access tokens.

## Root Cause

The new distributed session cache introduced in v2.18 incorrectly invalidated some refresh-token sessions.

## Resolution

The authentication service was rolled back to the previous token refresh implementation.

A permanent fix is being developed before the feature is re-enabled.
