# NimbusFlow v2.18 Release Notes

Release Date: August 15, 2026

## Authentication

Version 2.18 introduces a new token refresh implementation intended to reduce authentication latency.

The authentication service now performs refresh-token validation through the distributed session cache.

## API Gateway

Improved request routing performance for high-volume customers.

## Known Issues

Some customers using long-lived refresh tokens may experience intermittent `TOKEN_EXPIRED` errors after upgrading to version 2.18.

The authentication engineering team is investigating the issue.
